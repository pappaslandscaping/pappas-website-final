# Pappas & Co. Landscaping - Custom Website

Modern, professional website with your brand colors and logo.

## ⚠️ CRITICAL - Keep Files Together!

**ALL files must be in the SAME folder when uploading to Netlify:**

```
website-folder/
├── index.html
├── about.html
├── styles.css
├── script.js
├── quote.html
├── quote.css
├── quote.js
├── logo-horizontal.svg  ← REQUIRED! Logo won't show without this
├── logo-icon.png
└── Qualy.otf           ← Custom font
```

## 🚨 LOGO NOT SHOWING?

Make sure **logo-horizontal.svg** is in the same folder as index.html when you upload to Netlify!

## Quick Start

1. Download ALL files to one folder
2. Drag entire folder to Netlify
3. Done!

## Brand Assets

- Forest Green: `#2e403d`
- Lime Accent: `#c9dd80`  
- Cream: `#fbf8f1`
- Font: Qualy (custom)

## Updating Netlify

1. Go to [app.netlify.com](https://app.netlify.com)
2. Click your site: **charming-liger-d717b3**
3. Scroll to "Deploys" section
4. Drag your **entire folder** into the upload box
5. Wait 30 seconds - done! ✅
